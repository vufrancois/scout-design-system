Usage Guidelines

Default Props
size={24}, strokeWidth={2}, color="currentColor". Inherits text color automatically.
Button Icons
Use size={16} or {20} inside buttons. Place before label with 8px gap. Icon-only buttons need aria-label.
Consistency
Never mix icon libraries. Lucide only across both Buyer and Vendor apps. Same icon = same meaning everywhere.

Rules
