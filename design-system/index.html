Usage Guidelines

Default Props
size={24}, strokeWidth={2}, color="currentColor". Inherits text color automatically.
Button Icons
Use size={16} or {20} inside buttons. Place before label with 8px gap. Icon-only buttons need aria-label.
Consistency
Never mix icon libraries. Lucide only across both Buyer and Vendor apps. Same icon = same meaning everywhere.

Formatting

Canonical currency and date formats. A value is never formatted two different ways on two different screens.

Currency

ContextFormatExample
Default (prices, totals, line items)Symbol prefix, no space, 2 decimals$1,907.75
Vendor financial tablesDefault + ISO code suffix$1,907.75 USD
Stat cards / aggregates onlyAbbreviated, 1 decimal$45.3K · $1.2M
Negative amountsMinus before symbol, never parentheses-$45.00
ZeroShow as a value, never "Free"$0.00

Never drop cents in tables or documents. Implementation: Intl.NumberFormat('en-US', { style: 'currency', currency: 'USD' }).

Date & Time

ContextFormatExample
Standard date (tables, details)MM/DD/YYYY — zero-padded07/13/2026
Date with time12-hour clock, minutes always shown07/13/2026, 2:30 PM
Recent activity (< 7 days)Relative, full date in tooltip2h ago · Yesterday
Date rangeEn dash with spaces12/11/2026 – 12/13/2026

US format everywhere — MM/DD/YYYY, always zero-padded, never spelled-out months in UI. Implementation: Intl.DateTimeFormat('en-US', { month: '2-digit', day: '2-digit', year: 'numeric' }).

Charts

Data-viz color rules. Charts are implemented with the app's charting library — the system governs colors, formatting, and labels, not the chart code.

Categorical Ramp

Series colors in order, built from the blue scale. Use in sequence — first series always gets blue-800.

1 · blue-800
2 · blue-500
3 · blue-300
4 · blue-200
5 · border

Rules

• Single-series charts (bars, lines, areas): --blue-400 fill.
• Axis and tick labels: 9–10px, --muted-foreground; gridlines and axis rules use --border.
• Chart axis dates use MM/DD shorthand (06/18); full MM/DD/YYYY everywhere else.
• Donut center labels: value 26px/700 + 11px muted caption. Legends use 8px dots + 13px labels with right-aligned 600-weight values.

Metric Tile

Solid-accent KPI tiles for dashboards. Hero variant centers a large value; compact variant stacks label, value, and note. Always solid single-tone fills with white text.
